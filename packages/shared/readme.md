This workspace package is the shared source used by the
[maily.cn shadcn distribution](../../readme.md). The `@maily-to/shared` name remains
unchanged because it is part of the upstream package graph.

## Recommended installation: maily.cn source

Install the complete fork through shadcn using the
[root maily.cn instructions](../../readme.md). Shared renderer utilities are included
automatically in the generated registry block.

## Upstream-compatible package build

The command below installs the published `@maily-to/shared` npm package. It is kept
for compatibility and package development; it does **not** install the source-owned
`maily.cn` registry block.

```sh
pnpm add @maily-to/shared
```
